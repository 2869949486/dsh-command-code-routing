# Command-Code-Routing

[简体中文](README.md) · [English](README.en.md) · **Русский**

Плагин для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`), который по-настоящему
задействует подписку [Command Code](https://commandcode.ai): **пул аккаунтов + маршрутизация по окнам
кредитов**, а также **панель использования по моделям** — один пакет, одна страница в настройках.

- **Клиент**: одна страница `settings.section`, обновление каждые 60 секунд; пул аккаунтов можно добавлять,
  редактировать и удалять, таблица моделей несёт теги возможностей, а бейдж в поле ввода показывает именно
  тот маршрут, по которому вы реально идёте в данный момент; интерфейс на 10 языках, следует за браузером.
- **Хост**: два эндпоинта — `GET /command-code-usage.json` (использование, `?refresh=1` принудительно
  обновляет) и `GET|POST /command-code-quota-router.json` (пул и маршрутизация; действия ниже).

## Установка

Установка из репозитория (единственный канал распространения — пакета npm нет):

```bash
git clone https://github.com/2869949486/dsh-command-code-routing
```

Затем укажите профилю на этот код, например в `~/.dsh/profiles/desktop/package.json`:

```json
"dependencies": { "dsh-command-code-routing": "link:D:/path/to/dsh-command-code-routing" }
```

И добавьте то же имя в `dsh.profile.bundles`. После изменения **перезапустите DSH**: плагины хоста
загружаются только при запуске.

Пакет поставляется со своим `cordis.patch.yml`: один провайдер (`commandcode` через
`/provider/v1/chat/completions`) и **единственная** вставка (`id: command-code-router`). Подобъекты `usage:` и
`router:` хранят конфигурацию панели и маршрутизации соответственно (у обеих есть `path`, поэтому они не могут
делить одно плоское пространство имён).

```yaml
- insert:
    - id: command-code-router
      name: 'dsh-command-code-routing'
      config:
        vendor: commandcode
        apiKeyRef: COMMANDCODE_API_KEY
        usage:
          path: /command-code-usage
          plan: goat
        router:
          path: /command-code-quota-router
          statusUrl: null            # У Command Code нет status feed
          routes:
            - primary: { provider: commandcode, model: deepseek/deepseek-v4.1-flash }
              fallback: { provider: deepseek-account, model: deepseek-flash }
            - primary: { provider: commandcode, model: deepseek/deepseek-v4-pro }
              fallback: { provider: deepseek-account, model: deepseek-v4-pro }
```

Ключи верхнего уровня применяются к обеим половинам; ключи внутри `usage:` / `router:` переопределяют только
свою половину. `usage.plan` определяет только то, откуда берётся число месячного лимита (`goat`); фактическое
использование всегда берётся из ответов API.

### Учётные данные

`apiKeyRef` (по умолчанию `COMMANDCODE_API_KEY`) разрешается через seam учётных данных хоста, не сохраняется в
базе и не попадает в этот репозиторий. Остальные аккаунты пула адресуются как `COMMANDCODE_API_KEY_<ID>`
(например, `COMMANDCODE_API_KEY_A1`); ключ текущего активного аккаунта зеркалируется в
`COMMANDCODE_API_KEY` — это та ссылка, которую читает провайдер, поэтому переключение аккаунтов не требует
изменения конфигурации провайдера.

## Считаются кредиты, а не проценты

Command Code работает по принципу «из подписного лимита вычитаются доллары», поэтому адаптер сворачивает два
эндпоинта в три окна, которые панель понимала всегда:

| Окно панели | Источник данных | Доля лимита |
| --- | --- | --- |
| 5 часов (rolling) | `windowLimits.fiveHour` | 20% |
| Эта неделя | `windowLimits.weekly` | 50% |
| Этот период | `credits.monthlyCredits` + `subscriptions.currentPeriodEnd` | 100% |

`GET /alpha/billing/credits` даёт по каждому скользящему окну использованное/верхний предел и остаток
кредитов, а `GET /alpha/billing/subscriptions` — id тарифа и время окончания периода. Месячный лимит
выводится обратно из недельного верхнего предела (`weekly.cap / 0.5`), поэтому смена тарифа — это правка
конфигурации, а не кода. Цены моделей встроены (вход / выход / чтение кэша / запись кэша, $/Mtok), и столбец
по моделям суммируется именно по ним.

Поскольку API возвращает доллары, а не округлённые проценты, «обратный вывод тарифного плана по процентам» у
этого вендора отключён. **Пиковые цены при этом настоящие**: каталожная цена — это **непиковая** цена (17
часов в сутки), а модели DeepSeek с отметкой peak в будние дни по UTC `01–04`, `06–10` (по пекинскому времени
09:00–12:00, 14:00–18:00) тарифицируются в **2 раза** дороже. Это правило записано в `PEAK` / `peakFactor` в
`commandcode.js`, поэтому оценки стоимости и документ цен удваиваются только для этих моделей и ни для кого
больше: `deepseek-v4-flash-fast` и тариф `ultrafast` не имеют строки peak на странице цен и остаются по плоской
цене.

Бесплатные ознакомительные (preview) модели ограничиваются по количеству запросов, а не по кредитам:
`stealth/glyph-cluster:free` — 1000 запросов/день, `thinkingmachines/inkling-2-small:free` — 200
запросов/день. На панели их лимит отображается как неограниченный, а стоимость — как 0; они никогда не
расходуют лимит тарифа.

## Пул аккаунтов и переключение при отказе

Порядок аккаунтов — это порядок использования; в любой момент есть только один «текущий аккаунт».

- **A исчерпан — автоматически используется B**: при `QUOTA` / `ACCOUNT_QUOTA` / HTTP 429 с подтверждённо
  исчерпанными окнами или при ошибке класса аутентификации (`AUTH`, `INVALID_CREDENTIAL`,
  `MISSING_CREDENTIAL`, …) аккаунт помечается непригодным (для ошибок лимита — до сброса окна, для ошибок
  аутентификации — на 30 минут), маршрутизация переключается на следующий включённый аккаунт и **повторяет
  попытку на том же шаге** — весь ход разговора не деградирует.
- **Изолируется только одна модель**: когда одна модель сообщает об исчерпании, а в пуле ещё есть лимит,
  изолируется только эта модель (по умолчанию 30 минут), а остальные модели продолжают расходовать лимит.
- **Пул исчерпан целиком**: только тогда этот путь откатывается целиком (по умолчанию `deepseek-account`),
  каждые 30 минут или в момент сброса rolling-окна проверяется один раз через credits API с нулём токенов и
  автоматически возвращается после восстановления.
- **Пропускная способность / перегрузка вышестоящего сервиса**: при `router.fallbackOnCapacity: true`, даже
  если лимит не исчерпан, но вышестоящий сервис возвращает 429 класса пропускной способности, происходит
  откат; первая проба после отката начинается через `capacityFallbackDelayMs` (60 секунд), поскольку отказы
  по пропускной способности обычно проходят за несколько минут. На странице настроек есть кнопки «Перейти на
  официальную подписку / Вернуться на подписку», также можно напрямую выполнить
  `POST /command-code-quota-router.json {"action":"fallback"}` / `{"action":"primary"}`.
- **Сбой на полпути не теряет шаг**: повторная попытка происходит внутри того же вызова `llm/stream`; на месте
  перенаправляется только попытка основной стороны, «не выплюнувшая ни одного chunk». Как только первый
  символ выведен, поток принадлежит вызывающей стороне, и сбой выбрасывается как есть, но **маршрут всё равно
  переключается**, поэтому повторная попытка этого шага попадает на сторону отката, а не снова в ту же стену.
- **Восстановление требует 10 минут непрерывной чистоты**: во время отката проба выполняется каждые 60
  секунд, и трафик возвращается только после `recoverStableMs` (10 минут) непрерывных успехов; любой сбой
  посередине обнуляет окно и начинает заново — это решение проблемы «вышестоящий сервис дёргается, и маршрут
  прыгает туда-сюда».
- **Сброс**: очищает все метки «лимит исчерпан / сбой аутентификации» и немедленно возвращается в пул
  аккаунтов, не трогая аккаунты и ключи.

## Эндпоинты

`GET /command-code-usage.json` → `{plan, configuredPlan, detectedPlan, clock, peak, usage, usageError,
accounts[], activeAccount, models[], totals, pricing}`. `?refresh=1` принудительно обновляет чтение лимита;
`POST {"action":"refresh"}` эквивалентен; `POST {"action":"syncPricing"}` перечитывает публичный прайс (у
этого вендора по умолчанию отключено).

`GET /command-code-quota-router.json` → `{mode, reason, cause, active, accounts[], quarantine, routes[],
upstream, net, lastFailure}`; ключи всегда маскируются (возвращается только `hint`). Тот же путь через
`POST {action}` поддерживает `netcheck`, `add`, `update`, `remove`, `activate`, `move`, `probe`, `status`,
`fallback`, `primary`, `reset`. `GET …?key=<id аккаунта>` получает ключ одного аккаунта и используется
только локальным полем ввода «редактировать ключ».

## Модели

Блок провайдера заявляет модели, которые подписка GOAT действительно может вызывать: 62 на
OpenAI-совместимой линии. Id моделей сохраняют префикс вендора (`deepseek/deepseek-v4.1-flash`,
`moonshotai/Kimi-K3.1-Pro`): это id в протоколе, а DSH передаёт provider и model раздельно, поэтому косая
черта безопасна. Для всех маршрутов `max_tokens` единообразно равен 32000, а `reasoning_effort` — максимум до `max`.

В пакете подключён только **один** провайдер: `commandcode`. Command Code также предоставляет серию Claude
через протокол Anthropic messages (`/provider/v1/messages`), но GOAT покрывает только `claude-sonnet-5-5` и
`claude-haiku-5-5` (остальные относятся к тарифу premium и требуют `individual-pro` и выше), поэтому провайдер
Claude не заявляется: в селекторе и на панели остаются только те модели, за которые подписка действительно
платит.

## Правила лимитов

«Месячный предел» каждого модели на панели равен лимиту тарифа (базовый GOAT — $70, выводится из weekly cap
эндпоинта `/alpha/billing/credits`, делённого на 50%), а 5 часов и неделя составляют соответственно 20% и 50%
от него. У DEAL-моделей Command Code есть отдельно опубликованный повышенный (boosted) лимит; в пакете он
записан жёстко по столбцу GOAT: `deepseek/deepseek-v4.1-flash`, `z-ai/glm-5.3-flash`,
`inclusionai/ling-3.1-flash`, `inclusionai/ling-3.1-flash-1019` — $100 (см. `BOOSTED_ALLOWANCE_USD` в
`commandcode.js`).

## Генерация изображений

У Command Code нет вывода изображений: все `/provider/v1/images/*` возвращают 404, а в каталоге моделей нет ни
одной модели с выводом изображений (есть только мультимодальные модели понимания с «вводом изображений», такие
как `Qwen/Qwen3.8-Omni-Flash`). Поэтому этот пакет **управляет только текстом и кредитами** и не подключает
никаких инструментов генерации изображений; если нужны изображения, подключите отдельный бэкенд, умеющий их
генерировать.

## Совместимость

- `dsh >= 0.2.0-rc.1`: потоковые вызовы идут через публичный waterfall `llm/stream`.
- `dsh >= 0.2.2-rc.1`: дополнительно перед каждым шагом выравнивает через `agent.model.select()`, чтобы
  постоянные заголовки запросов и источник assistant следовали за реально выбранной стороной.
